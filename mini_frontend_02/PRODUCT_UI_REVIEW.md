# 물품 생성 · 조회 화면 개선 결과

## 작업 목표

기존 Python/Streamlit 코드 수준을 유지하면서 `물품 생성`과 `물품 조회` 두 화면만
쉽게 이해하고 관리할 수 있도록 개선했습니다.

## 서버 확인 결과

- 정상 API 서버: `https://zero2-mini-project-2.onrender.com`
- 전체 조회: `GET /product/getall`
- 물품 생성: `POST /product/create`
- 기존 생성 화면의 `https://zero2-mini-project-2-kg1s.onrender.com` 주소는 응답하지 않아
  조회 화면과 동일한 정상 서버 주소로 통일했습니다.

## 물품 생성 화면

- ID, 물품명, 가격을 한 카드 안에서 입력하도록 구성
- 등록 전 입력 내용을 한 줄로 미리 표시
- 빈 물품명과 0원 가격을 서버 전송 전에 검사
- 서버 연결 실패, 입력 형식 오류, 기타 서버 오류를 구분해서 안내
- 등록 완료 후 생성된 물품 정보를 표시
- 완료 메시지 아래에서 물품 조회 화면으로 바로 이동 가능

## 물품 조회 화면

- 전체 물품 수, 평균 가격, 가격 합계를 상단에 표시
- 물품명과 ID를 하나의 검색창에서 검색 가능
- ID, 낮은 가격, 높은 가격, 이름 기준 정렬 제공
- 카드 반복 대신 한눈에 보기 쉬운 표 사용
- 새로고침 버튼과 검색 결과 개수 표시
- 서버 연결 실패 시 다시 불러오기 버튼 제공

## 유지보수할 때 알아둘 부분

두 파일 위쪽의 `API_BASE_URL`이 서버 주소입니다.
나중에 서버 주소가 바뀌면 아래 두 파일의 값을 같은 주소로 변경하면 됩니다.

- `app_pages/05_product_create.py`
- `app_pages/06_product_select.py`

`try`와 `except`는 서버가 꺼졌거나 인터넷 연결이 끊겨도 앱 전체가 오류 화면으로
바뀌지 않게 보호하는 부분입니다.

각 주요 처리 부분에는 초보자도 흐름을 따라갈 수 있도록 한글 주석을 추가했습니다.

## 검토 포인트

1. 물품 가격으로 0원을 허용해야 하는지
2. 물품 ID를 사용자가 입력할지, 서버가 자동 생성하게 바꿀지
3. 조회 표에서 수정·삭제 기능도 다음 단계에 다시 추가할지

## 검증 결과

- Python 3.12 문법 검사: 통과
- Streamlit 로컬 서버 실행: 성공 (`http://127.0.0.1:8501`)
- 브라우저 자동 화면 검사: 브라우저 연결 환경 문제로 미실행
- 물품 조회 API: HTTP 200 응답 및 물품 4건 확인
- 물품 생성 입력 검사: 코드에서 빈 물품명과 0원 이하 가격 차단 확인
- 실제 물품 생성 요청: 서버 데이터를 변경하지 않기 위해 실행하지 않음
- 임시 서버 및 테스트 로그: 검증 후 종료 및 삭제
